## Gen 2 adaptation

Gen1Recomp's Gen 2 `World:replaceBlock(index, blockId)` writes the live block
buffer directly, records the original block for regrowth, refreshes map images,
and emits `world.block_replaced`. It bypasses `Map:setBlock`, and the event does
not provide the previous block. `BlockMeshRefresh` wraps the real method to
capture that value and derive bx/by from the 1-based index. It suppresses its
duplicate event notification, preserves the engine result/error, and retains
the direct Map write and conservative event-only fallbacks.

Both generations use four-by-four 8px graphics tiles per block. The port compares
graphics tile IDs, not Gen 2 collision bytes. Only owned prop vertices change;
ground and neighboring map meshes remain drawable. Replacement geometry and
shading still require the existing budgeted background rebuild. This does not
eliminate all map rebuilding or promise a frame-time improvement on every device.

Full/body terrain and grass/flower ownership survive disk and RAM serialization.
Revision 22 invalidates old records once. The existing immutable Gen 2 snapshot
prevents a cut map from replacing the original precache; regrowth can reuse it.

Reflection transforms keep the Gen 2 `half` sprite width, lean override, facing,
and anchor behavior. Allocation is skipped without visible water, readable
depth, or enabled water. Failed cast draws are discarded, and transform/shader
state is restored. Existing battle and Stadium rendering code is unchanged.

## Gen 4 tight-frame data follow-up

Imported dimensions from `dev/gen4_front_tight-1.10.3/data`: 386 regular and
386 shiny definitions. A normalized source comparison verified that the supplied
tables change only width/height. Original dimensions are retained as
`legacyLayout`. The shared decoder selects exact tight or original atlas sizes
and rejects unknown layouts. Paths, timings, counts and Gen 2 battle ownership
remain unchanged. No PNG assets were copied. Supplied tight PNGs can be overlaid
incrementally; retain these merged data tables instead of overwriting them.

The complete metadata decoder test passed 6,948 checks across both layouts for
all 772 definitions. Animation ownership and Gen 2 Summary ownership tests pass.

The separate small-Pokemon summary audit found that Gen 2's existing FIT path
bottom-aligns visible art within 56x56. Synthetic 20px and 40px drawings occupy
rows 36..55 and 16..55 respectively, before and after the metadata port. The
Gen 1 master FULL path top-aligns the same drawings at rows 0..19 and 0..39;
that Gen 1 behavior remains unchanged. This is a source/headless verification,
not a reproduction on the user's phone.

## FIT/FULL interface scaling follow-up

FULL retains native pixels. Summary FULL uses the first frame's opaque bounds:
`top = max(0, 56 - firstHeight) - firstY0`. The offset remains fixed across all

within 72px. Oversize art remains unscaled and may overlap the UI.

## Silver menu and terrain follow-up

The user's build exposed that the preceding adapters covered Gen 1 classes only.
Gen 2's real SummaryMenu and PokedexMenu bypass those classes and the sprite
hook. New adapters replace their drawPic methods, shared by normal/widescreen
panels, without replacing page layouts. Summary FULL retains the first-frame
bottom/top rule; the native Gen 2 Dex centers within its 56px portrait at the
supplied tile origin. Native unseen entries and Unown forms retain their own
rendering. OFF/MODDED and unavailable artwork delegate to native drawing.

The interface test now loads the actual engine Gen 2 classes and passes 31
checks, including replacement, first-pose alignment, native fallback and graphics
state restoration. This catches the wrong-class integration missed previously.

BattleScene.groundY now samples both battler cells, uses their higher supporting
height, and adds one world pixel of clearance shared by cards/effects. Four
floor-selection checks pass, along with battle layer order, effect-facing,
Stadium circle depth, Gen 2 battle adapter, and interface ownership/defaults.
Syntax and whitespace checks pass. Route 32 visual verification and third-party
UI mod compatibility still require an in-game test.

## Pidgeotto and opponent anchor follow-up

Inspected the installed Gen 4 Pidgeotto atlas (1136x180, 71x90 cells). Its first
and resting poses occupy y=6..83: 78px tall. Dex FULL now allows the signed
centering offset, `(56 - firstHeight) / 2` rounded down, minus firstY0. This
moves Pidgeotto up 11 pixels compared with the clamped formula. Small Dex poses
and Summary's deliberate oversized top alignment are unchanged.

The remaining Route 32 clipping came from the capture anchor, independently of
terrain height: native Silver drawPic top-pins oversized enemy fronts, but the
world capture still anchored them at row 56. The anchor now uses max(56, height)
for opponent Pokemon, retaining canvas margins and animation movement. Trainer
and substitute anchors retain their original behavior. Faint sinking remains
an explicit world-space effect.

The real-atlas headless test checks all 23 Pidgeotto and 26 Ekans frames against
that placement. Their resting poses retain 6 and 3 atlas pixels of clearance,
respectively; every frame stays above the floor. Interface checks now total 33,
including oversized Dex centering and unchanged Summary top alignment. Falkner
and Route 32 still need in-game visual verification.

## Summary playback and tree regrowth follow-up

Summary playback now advances from the real Gen 2 stepPicAnim method using the
engine FixedStep.STEP. This works even when a menu caller retained an earlier
update method; the adapter no longer adds a second tick from Summary.update.
The real-class test verifies original-update playback, normal-update playback,
and looping, bringing the interface suite to 35 checks. This validates the
retained-callback failure path; the user's precise runtime freeze has not been
reproduced in-game.

World.restoreBlocks restores block buffers directly and emits no block-replaced
event. Its adapter now invalidates only map IDs with changed restoration data,
preventing retained cut meshes or pending cut jobs surviving route re-entry.
The existing immutable cache remains available for pristine geometry reloads.
The actual World method regression passes 21 checks, including tree block
restoration, geometry invalidation and no-op re-entry. Prepared Gen 2 static
geometry reuse, Lua syntax and whitespace checks pass. Gameplay verification
of animation and leaving/re-entering a cut route remains pending.
